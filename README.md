# PythonTech

**Версия 0.2.0 · Python Core готов · Web и NumPy в разработке**

Настольное приложение для изучения Python на русском языке.
Принцип курса: **кратко, понятно, красиво и легко запомнить**.

## Уже доступно

- **54 урока Python Core** в 9 последовательных разделах.
- **108 заданий с проверкой**, подсказками и объяснениями.
- **54 самостоятельные практики** с конкретными критериями проверки.
- Короткая теория, примеры кода и памятка в каждом уроке.
- Мини-проекты и итоговый **трекер привычек** с JSON-хранилищем и тестами.
- Поиск тем, переход между уроками, копирование кода и сохранение прогресса.
- Отдельные отметки самостоятельной практики, адаптивный интерфейс и настройка уменьшения анимации.

## Запуск

Нужен **Python 3.10+**. Интерфейс работает на **PySide6 / Qt Quick**.

```sh
git clone https://github.com/unbowed-scripts/PythonTech.git
cd PythonTech
python -m venv .venv
```

**Linux / macOS:**

```sh
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

**Windows:**

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

Если команда `python` не найдена, используй `python3` на Linux/macOS или `py` на Windows.
После установки зависимостей курс работает без интернета.

## Как проходит практика

Прочитай урок → разбери пример → реши короткие задания → напиши свою программу → проверь её по критериям.

Самостоятельный код пишется и запускается в отдельных `.py`-файлах: встроенного редактора и выполнения кода пока нет.
Отметка практики — твоя самопроверка. Прогресс хранится локально, без аккаунта и облачной синхронизации.

## Итоговый проект

В `examples/habit_tracker/` лежит рабочий ориентир трекера привычек: добавление, список, отметки по датам и удаление.
Сначала попробуй написать свою реализацию.

```sh
python -m examples.habit_tracker --help
python -m examples.habit_tracker add "Учить Python"
python -m examples.habit_tracker list
```

## Проверка

Из корня проекта, интерпретатором с установленными зависимостями:

```sh
python -m unittest discover -s tests -v
```

23 теста проверяют материалы, все 54 примера, прогресс, навигацию, QML-интерфейс и итоговый проект.
Тесты используют временные данные. Интерфейс проверяется в offscreen-режиме; проверка на Windows/macOS отдельно пока не проводилась.
