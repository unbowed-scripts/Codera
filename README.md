# PythonTech 0.5.0

**Офлайн-приложение для изучения Python: понятная теория, примеры кода и практика.**

Учись на русском языке в своём темпе. Читай объяснения, разбирай код, проверяй ответы и создавай свои программы. Приложение бесплатное, с открытым исходным кодом. Для уроков не нужны регистрация и интернет; прогресс хранится на твоём компьютере.

## Что доступно

| Курс | Уроки | Чему научишься |
| --- | --- | --- |
| Python Core | 54 урока, 9 разделов | От переменных и циклов до файлов, классов, тестов и трекера привычек |
| Python Web | 24 урока, 4 раздела | HTTP, Flask, HTML, формы, JSON API, SQLite, защита данных и тестирование |

В каждом уроке есть теория с выделением главного, рабочий пример с разбором, два вопроса с проверкой и самостоятельная практика. Всего — **78 уроков, 156 вопросов, 13 итоговых тестов и 13 мини-проектов**.

В подсказках показан код, который можно выделить и скопировать. Ошибки в ответах можно исправлять без ограничения попыток. NumPy и другие языки пока представлены программами будущих курсов.

## Как начать

Готовые сборки находятся на [странице релизов](https://github.com/unbowed-scripts/PythonTech/releases). Выбери опубликованную сборку для своей системы. Версия исходников в этой ветке — 0.5.0; готовые установщики могут появиться позже.

- **Windows:** запусти установщик либо распакуй портативную версию целиком и открой `PythonTech.exe`. Не перемещай исполняемый файл отдельно от остальных файлов сборки.
- **Linux:** установи пакет `.deb` или распакуй архив и запусти `PythonTech` из его папки.

В приложении выбери **Python**, затем направление **Python Core** или **Web**. Если начинаешь с нуля, сначала пройди Core. Уроки можно открывать свободно: жёсткой блокировки Web нет.

## Как заниматься

1. Прочитай теорию и посмотри пример.
2. Ответь на вопросы и нажми **«Проверить ответы»**. При ошибке прочитай подсказку и попробуй ещё раз.
3. Выполни практику в своём `.py`-файле. Приложение не запускает введённый тобой код: запускай его установленным Python.
4. Сравни результат с критериями и отметь **«Написал, запустил и проверил самостоятельно»**.
5. После шести уроков раздела пройди итоговый тест: шесть коротких ответов и два вопроса по коду.
6. Выполни мини-проект. При необходимости открывай пошаговые подсказки и полный пример с объяснением.

Урок считается пройденным после правильных ответов. Выполнение практики и проекта ты отмечаешь самостоятельно — эти отметки не являются автоматической оценкой программы.

Кнопка **«Продолжить обучение»** возвращает к следующему уроку или незавершённому итогу раздела. Пройденные уроки, тесты и отметки практики сохраняются между запусками. Черновики ответов, вставленный для ИИ код и вопросы сохраняются только в текущем запуске приложения.

## Python Web

Курс ведёт от первого HTTP-запроса к локальному сервису заметок:

1. **Как устроен Web:** клиент и сервер, HTTP, URL, JSON, разбор запросов, HTML и CSS. Мини-проект — инспектор запроса.
2. **Первое веб-приложение:** Flask, маршруты, шаблоны, формы, ошибки API и перенаправления. Мини-проект — каталог заметок с HTML и JSON.
3. **Данные и безопасность:** SQLite, параметры SQL, CRUD, cookie, сессии, CSRF и транзакции. Мини-проект — постоянное хранилище заметок.
4. **Тесты и законченный сервис:** фабрика приложения, настройки, логи, HTTP-тесты, временная база и подготовка к публикации. Итог — локальный сервис заметок с созданием, поиском, редактированием и удалением.

Для чтения курса дополнительных пакетов не нужно. Для запуска практики потребуется Python 3.10+ и Flask. Установи Flask один раз в отдельное окружение:

```bash
python -m venv .venv
```

Активируй окружение:

- Windows PowerShell: `.venv\Scripts\Activate.ps1`
- Linux/macOS: `source .venv/bin/activate`

Затем установи Flask:

```bash
python -m pip install "Flask>=3.1,<4"
```

Большинство примеров можно сохранить как `app.py` и запустить командой `python app.py`: они используют тестовый клиент Flask без сети. Чтобы открыть Flask-пример в браузере:

```bash
python -m flask --app app run
```

Открой `http://127.0.0.1:5000/`. Остановка сервера — **Ctrl+C**. Интернет нужен для первоначальной установки зависимостей; дальше уроки и локальные примеры работают без него.

Полный [сервис заметок](examples/web_notes/README.md) включён в исходники. Из корня проекта:

```bash
python -m pip install -r examples/web_notes/requirements.txt
python -m flask --app examples.web_notes.app run
```

Блокнот рассчитан на одного пользователя и локальный запуск. Курс объясняет, что нужно добавить перед публикацией сервиса для других пользователей.

## Необязательный ИИ-помощник

Обычные подсказки работают офлайн. Если хочешь помощь своей модели, открой **Настройки → ИИ-помощник**:

1. Укажи адрес совместимого Chat Completions API, название модели и свой API-ключ.
2. Нажми **«Подключить и проверить»**.
3. У нужного вопроса или практики открой **«Помощь ИИ»**, при необходимости вставь свой код и нажми **«Получить подсказку»**.

Модель получает условие выбранного задания, учебный пример, текущий ответ, вставленный код и твой вопрос. Она не читает файлы с компьютера автоматически. Ответ ИИ не меняет прогресс и не заменяет запуск программы.

Запросы отправляются прямо по указанному тобой адресу. Плата и ограничения зависят от провайдера. При подключении отправляется короткий проверочный запрос, учебные данные — только по кнопке получения подсказки.

Адрес и название модели сохраняются. **Ключ хранится только до закрытия приложения**; кнопка «Отключить» удаляет его из текущего подключения. Для удалённого API нужен HTTPS. Для локальной модели можно указать, например, `http://localhost:11434/v1`; модель должна быть установлена и запущена отдельно. При работе с локальной моделью интернет не нужен.

## Настройки и управление

- Четыре темы: зелёная, синяя, серая и светлая. Выбор сохраняется.
- «Меньше анимации» отключает движения, которые могут отвлекать.
- Интерфейс адаптируется к узкому окну.
- **Tab** перемещает фокус; **Space/Enter** активирует кнопку; **Escape** закрывает окно настроек.
- Русский интерфейс доступен; английский и украинский пока готовятся.

## Запуск из исходников

Нужен Python 3.10+ с поддержкой PySide6. Скачай исходники, открой терминал в папке проекта и выполни:

```bash
python -m venv .venv
```

Активируй окружение командой для своей системы, как показано выше, затем:

```bash
python -m pip install -r requirements.txt
python main.py
```

Flask устанавливается отдельно только для запуска Web-примеров; самому PythonTech он не нужен.

## Если что-то не работает

- **Приложение не запускается из исходников:** проверь, что окружение активно и зависимости из `requirements.txt` установлены.
- **`No module named flask`:** установи Flask в то окружение, из которого запускаешь Web-пример.
- **Порт 5000 занят:** запусти `python -m flask --app app run --port 5001` и открой `http://127.0.0.1:5001/`.
- **ИИ не подключается:** проверь адрес API, идентификатор модели, ключ и доступный баланс провайдера. Учиться можно и без ИИ.
- **Вопрос не засчитывается:** вводи только требуемый ответ, учитывая регистр и пробелы внутри строки. Лишние пробелы по краям не мешают проверке.
