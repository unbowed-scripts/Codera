# PythonTech

Настольное приложение для изучения программирования. Интерфейс переписан на **QML / Qt Quick**, учебная логика остаётся на Python. Для анимации используется движок Qt Quick, без Python-перерисовки каждого кадра и без браузера.

## Запуск

Python 3.10+ и полный пакет PySide6:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

В текущем рабочем каталоге зависимости уже установлены в `.venv`.

В Windows используйте `.venv\Scripts\python.exe` вместо `.venv/bin/python`.
Если системный PySide6 не содержит Qt Quick, `python3 main.py` автоматически перезапускается через существующую локальную `.venv`. Зависимости автоматически не скачиваются. После их установки приложение работает без сети. Установщик пока не создан.

## Что работает

- Тёмно-серый и зелёный интерфейс, логотип `[p.]`, приветствие, дуга выбора языка и матрица снизу вверх. Python доступен, JavaScript готовится.
- Ступень «Джуниор»: Python Core (54 урока), Web (10) и NumPy (10). Средний и высокий уровни пока отключены.
- Python Core полностью заполнен: 9 последовательных разделов, 54 урока, 108 коротких проверок, 54 задания на самостоятельное написание кода. В каждом уроке есть объяснение, пример, разбор, памятка и критерии самопроверки. Web и NumPy пока содержат только маршрут.
- Переход «Дальше» проходит через границы разделов. Прогресс разбора и самостоятельно отмеченной практики хранится раздельно. После итогового проекта доступен переход к маршруту Web.
- Итоговый проект — трекер привычек с JSON-хранилищем, CLI, валидацией и тестами. [Порядок обучения и критерии готовности к Web](docs/CORE_GUIDE.md).
- Обзор с продолжением обучения, поиск тем, список разделов, схема обучения с векторной горой, копирование примеров, проверка по Enter.
- Прогресс и настройка уменьшения движения сохраняются через прежнее хранилище `QSettings('PythonTech', 'Learning')`. Данные предыдущей версии подхватываются автоматически.
- Черновики ответов и позиции прокрутки страниц хранятся до закрытия приложения. Возврат к приветствию сохраняет текущий экран курса.
- Узкая навигация открывается поверх страницы и не меняет её ширину или прокрутку.
- Переходы меняют только прозрачность: 75 мс на затухание и 130 мс на появление. Новая геометрия и позиция прокрутки устанавливаются до появления текста. Повторный выбор текущей темы ничего не пересоздаёт. При быстрых кликах выбирается последняя тема.
- Проверка ответов не запускает автоматическую прокрутку; пространство для подсказок зарезервировано, чтобы задания не сдвигались.
- «Меньше анимации» отключает переходы и движение матрицы. На экране курса матрица не анимируется.

Редактор и запуск пользовательского кода внутри приложения пока не реализованы. Короткие задания проверяют ответы на вопросы по коду; самостоятельную практику выполняют в отдельных Python-файлах. Отметка практики — самопроверка, а не автоматическая оценка программы.

## Структура

- `main.py` — запуск приложения и загрузка QML.
- `backend.py` — навигационные данные, ответы, проверка, прогресс и позиции прокрутки.
- `curriculum.py` — структура курса и модели уроков.
- `core_content.py` — авторские материалы Python Core.
- `examples/habit_tracker/` — запускаемый ориентир итогового проекта.
- [docs/CORE_GUIDE.md](docs/CORE_GUIDE.md) — последовательность обучения и итоговая проверка.
- `qml/` — весь действующий интерфейс и анимации.
- `tests/` — проверки логики и работающего QML-интерфейса.
- [docs/DESIGN.md](docs/DESIGN.md) — устройство переходов, дизайн и ограничения проверки.
- `archive/widgets-before-qml.tar.gz` — резервная копия прежней реализации на Qt Widgets, включая её тесты.

HTML-макет `design/concept.html` и снимки без префикса `qml-` относятся к предыдущим версиям. Актуальные снимки — `design/qml-*.png`.

## Проверка

```sh
.venv/bin/python -m unittest discover -s tests -v
QT_SCALE_FACTOR=2 .venv/bin/python -m unittest discover -s tests -v
```

Тесты также запускают все 54 примера в отдельных процессах и временных папках, сверяют результаты, проверяют переходы между разделами и сохранение практики. Трекер проверяется на повторные даты, ошибки данных, сбой записи и перезапуск CLI.

Тесты интерфейса используют изолированное хранилище и offscreen/software-отрисовку. Они проверяют перенос старого прогресса, ответы, доступность всех маршрутов, клики, Enter, отсутствие движения заголовка при появлении, сохранение прокрутки страниц и списка тем, быстрые переключения и адаптацию к узкому окну. Предупреждения QML считаются ошибками теста.

На текущем Linux-компьютере отдельно проверен запуск через OpenGL с threaded render loop. Это не гарантия частоты кадров на каждом устройстве; Windows/macOS и установочные пакеты требуют отдельной проверки.
