PythonTech — бесплатное настольное приложение для изучения Python. Короткие объяснения, рабочие примеры и практика помогают перейти к своим программам. Уроки доступны без интернета и аккаунта. Прогресс хранится на твоём компьютере.

> **Языки:** README доступен на английском, русском и украинском. Интерфейс приложения и готовые уроки пока на русском. Английский и украинский интерфейсы запланированы.

## От основ к своему проекту

| Python Core | Python Web |
| --- | --- |
| **54 урока · 9 разделов** | **42 урока · 7 разделов** |
| Переменные, циклы, коллекции, функции, файлы, классы и тесты | HTTP, Flask, связи SQL, аккаунты, права, тесты и основы запуска |
| Итог: трекер привычек | Три приложения: заметки, каталог книг и личные задачи |

**96 уроков · 192 вопроса в уроках · 16 итоговых тестов · 16 мини-проектов**

- **Учись на практике.** В каждом уроке есть теория, код, разбор и самостоятельное задание.
- **Разбирай ошибки.** Исправляй ответы, открывай пошаговые подсказки и копируй примеры кода.
- **Продолжай в своём темпе.** Пройденные уроки, тесты и отметки практики сохраняются между запусками.
- **Настрой оформление.** Четыре темы, узкое окно, управление с клавиатуры и отключение лишней анимации.
- **Подключи ИИ при необходимости.** Используй свою совместимую модель. Обычные подсказки работают офлайн.

Для NumPy и других языков пока доступны программы будущих курсов, а не готовые уроки.

## Быстрый старт

### Скачать сборку

Выбери доступный пакет на [странице релизов](https://github.com/unbowed-scripts/PythonTech/releases). Версия исходников — **0.7.0**. Версия опубликованных установщиков может отличаться.

Подробности о сжатии курсов, загрузке уроков и совместимости прогресса: [хранение данных](docs/STORAGE.md).

- **Windows:** запусти установщик или распакуй весь портативный архив и открой `PythonTech.exe`. Сохраняй остальные файлы сборки рядом.
- **Linux:** установи пакет `.deb` или распакуй архив и запусти `PythonTech` из его папки.

### Запустить из исходников

Нужны **Python 3.10+ с поддержкой PySide6 6.8.2.1** и графическая среда. Для установки зависимостей потребуется интернет.

```bash
git clone https://github.com/unbowed-scripts/PythonTech.git
cd PythonTech
```

**Linux / macOS** — запуск из исходников; готовые сборки для macOS не предусмотрены:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

**Windows PowerShell:**

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

В командах ниже `python` должен указывать на созданное окружение. Активируй его: `source .venv/bin/activate` на Linux/macOS или `.\.venv\Scripts\Activate.ps1` в PowerShell. Вместо активации можно указывать полный путь к Python, как выше.

## Как заниматься

1. Выбери **Python → Python Core**. Если начинаешь с нуля, пройди Core первым. Уроки Web тоже можно открывать свободно.
2. Прочитай теорию и пример. Ответь на два вопроса и нажми **«Проверить ответы»**.
3. Выполни практику в своём `.py`-файле. Запусти его через Python и сравни результат с критериями.
4. После самопроверки отметь практику как выполненную.
5. Заверши шесть уроков раздела, чтобы открыть тест. Ответь верно на восемь вопросов, затем выполни мини-проект.

**Приложение проверяет короткие ответы, а не твою программу.** Оно не запускает код ученика. Практику и проекты ты отмечаешь самостоятельно. Черновики ответов, вопросы к ИИ и вставленный код хранятся только до закрытия приложения.

### Попробовать Web-проект

Сервис заметок показывает работу HTML-форм, JSON API, SQLite, поиска, редактирования и удаления. Из корня репозитория:

```bash
python -m pip install -r examples/web_notes/requirements.txt
python -m flask --app examples.web_notes.app run
```

Открой [localhost:5000](http://127.0.0.1:5000/). Для остановки нажми **Ctrl+C**. Flask нужен для запуска Web-примеров, но не для чтения курса или запуска PythonTech.

Заметки — первое полное приложение курса. Затем создай [каталог книг](examples/web_catalog/README.md) со связями таблиц и страницами списка, а после — [личный планировщик](examples/web_tasks/README.md) с аккаунтами и проверкой владельца. Итоговое задание — собственная доработка с тестами и инструкцией запуска. Все три примера предназначены для локального обучения. Программа и критерии завершения — в [Web-руководстве](docs/WEB_GUIDE.md).

## Необязательный ИИ-помощник

Открой **«Настройки → ИИ-помощник»**. Укажи адрес совместимого Chat Completions API, название модели и свой API-ключ. Нажми **«Подключить и проверить»**.

У задания открой **«Помощь ИИ»**, при необходимости вставь свой код и запроси подсказку.

| Что отправляется | Что сохраняется |
| --- | --- |
| Короткая проверка подключения; по запросу подсказки — контекст задания, пример, текущий ответ, вставленный код и вопрос | Адрес и название модели сохраняются. Ключ остаётся в памяти до отключения модели или закрытия приложения. |

Запросы идут прямо выбранному провайдеру. Его тарифы и ограничения действуют и здесь. Для удалённого API нужен HTTPS. Отдельно установленная локальная модель может работать без интернета по адресу вроде `http://localhost:11434/v1`. Помощник не читает файлы, не запускает код и не меняет прогресс. Проверяй его советы запуском программы.

## Технологии и разработка

| Часть проекта | Инструменты |
| --- | --- |
| Настольное приложение | Python, PySide6 6.8.2.1, Qt Quick / QML |
| Локальные настройки и прогресс | Qt `QSettings` |
| Web-практика | Flask 3.1+, SQLite, HTML / CSS, JSON |
| Проверки | Python `unittest`, Qt Test, скрипты проверки отображения |

```text
main.py / backend.py       Запуск и состояние приложения
curriculum.py             Структура курсов и сборка уроков
core_content.py           Материалы Python Core
web_content.py            Базовые уроки и сборка Web-курса
web_extended_content.py   Связи данных, пользователи и запуск
qml/                      Интерфейс, значки и превью тем
examples/                 Рабочие учебные проекты
tests/ / tools/           Тесты и инструменты разработки
docs/ / packaging/        Руководства и подготовка сборок
```

После установки зависимостей приложения и Web-примеров запусти тесты:

```bash
python -m unittest discover -s tests -v
```

На Linux без видимого окна добавь перед командой `QT_QPA_PLATFORM=offscreen QT_QUICK_BACKEND=software`.

Перед вкладом в проект прочитай [AGENTS.md](AGENTS.md). Делай изменения по одной задаче и добавляй нужные проверки. О воспроизводимой ошибке сообщи в [GitHub Issues](https://github.com/unbowed-scripts/PythonTech/issues), не публикуя ключи и личные данные.

<details>
<summary><strong>Если что-то не работает</strong></summary>

- **Приложение не запускается:** устанавливай зависимости и запускай программу одним окружением. В нём должен быть PySide6 с Qt Quick.
- **`No module named flask`:** установи `examples/web_notes/requirements.txt` тем Python, которым запускаешь пример.
- **Порт 5000 занят:** добавь `--port 5001` к команде Flask и открой [localhost:5001](http://127.0.0.1:5001/).
- **ИИ не подключается:** проверь адрес, идентификатор модели, ключ и ограничения провайдера. Учиться можно офлайн.
- **Ответ не засчитывается:** проверь регистр и пробелы внутри ответа. Пробелы по краям не учитываются.

</details>
