PythonTech — безплатний настільний застосунок для вивчення Python. Короткі пояснення, робочі приклади й практика допомагають перейти до власних програм. Уроки доступні без інтернету й облікового запису. Прогрес зберігається на твоєму комп’ютері.

> **Мови:** README доступний англійською, російською та українською. Інтерфейс застосунку й готові уроки поки російською. Український та англійський інтерфейси заплановані.

## Від основ до власного проєкту

| Python Core | Python Web |
| --- | --- |
| **54 уроки · 9 розділів** | **42 уроки · 7 розділів** |
| Змінні, цикли, колекції, функції, файли, класи й тести | HTTP, Flask, зв’язки SQL, облікові записи, права, тести й основи запуску |
| Підсумок: трекер звичок | Три застосунки: нотатки, каталог книг і особисті задачі |

**96 уроків · 192 запитання в уроках · 16 підсумкових тестів · 16 мініпроєктів**

- **Навчайся на практиці.** Кожен урок містить теорію, код, розбір і самостійне завдання.
- **Розбирай помилки.** Виправляй відповіді, відкривай покрокові підказки й копіюй приклади коду.
- **Продовжуй у своєму темпі.** Пройдені уроки, тести й позначки практики зберігаються між запусками.
- **Налаштуй оформлення.** Чотири теми, вузьке вікно, керування з клавіатури й зменшення анімації.
- **Підключи ШІ за потреби.** Використовуй власну сумісну модель. Звичайні підказки працюють офлайн.

Для NumPy та інших мов поки є плани майбутніх курсів, а не готові уроки.

## Швидкий старт

### Завантажити збірку

Обери доступний пакет на [сторінці випусків](https://github.com/unbowed-scripts/PythonTech/releases). Версія вихідного коду — **0.7.0**. Версія опублікованих інсталяторів може відрізнятися.

Стиснення курсів, завантаження уроків і сумісність прогресу описано в [нотатках про зберігання (російською)](docs/STORAGE.md).

- **Windows:** запусти інсталятор або розпакуй увесь портативний архів і відкрий `PythonTech.exe`. Залиш решту файлів збірки поруч.
- **Linux:** установи пакет `.deb` або розпакуй архів і запусти `PythonTech` з його теки.

### Запустити з вихідного коду

Потрібні **Python 3.10+ з підтримкою PySide6 6.8.2.1** і графічне середовище. Для встановлення залежностей потрібен інтернет.

```bash
git clone https://github.com/unbowed-scripts/PythonTech.git
cd PythonTech
```

**Linux / macOS** — запуск із вихідного коду; готових збірок для macOS не передбачено:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

**Windows PowerShell:**

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

У командах нижче `python` має вказувати на створене середовище. Активуй його: `source .venv/bin/activate` на Linux/macOS або `.\.venv\Scripts\Activate.ps1` у PowerShell. Замість активації можна вказувати повний шлях до Python, як вище.

## Як навчатися

1. Обери **Python → Python Core**. Якщо починаєш з нуля, спершу пройди Core. Уроки Web теж можна відкривати вільно.
2. Прочитай теорію та приклад. Дай відповіді на два запитання й натисни **«Проверить ответы»** (Перевірити відповіді).
3. Виконай практику у власному `.py`-файлі. Запусти його через Python і порівняй результат із критеріями.
4. Після самоперевірки познач практику як виконану.
5. Заверши шість уроків розділу, щоб відкрити тест. Правильно відповідай на вісім запитань, а потім виконай мініпроєкт.

**Застосунок перевіряє короткі відповіді, а не твою програму.** Він не запускає код учня. Виконання практики й проєктів ти позначаєш самостійно. Чернетки відповідей, запитання до ШІ та вставлений код зберігаються лише до закриття застосунку.

### Спробувати Web-проєкт

Сервіс нотаток демонструє HTML-форми, JSON API, SQLite, пошук, редагування й видалення. З кореня репозиторію:

```bash
python -m pip install -r examples/web_notes/requirements.txt
python -m flask --app examples.web_notes.app run
```

Відкрий [localhost:5000](http://127.0.0.1:5000/). Для зупинки натисни **Ctrl+C**. Flask потрібен для запуску Web-прикладів, але не для читання курсу чи запуску PythonTech.

Нотатки — перший повний застосунок курсу. Далі створи [каталог книг](examples/web_catalog/README.md) зі зв’язками таблиць і сторінками списку, а потім — [особистий планувальник](examples/web_tasks/README.md) з обліковими записами й перевіркою власника. Підсумкове завдання — власне розширення з тестами та інструкцією запуску. Усі три приклади призначені для локального навчання. Програма й критерії завершення — у [Web-посібнику](docs/WEB_GUIDE.md) російською.

## Необов’язковий ШІ-помічник

Відкрий **«Настройки → ИИ-помощник»** (Налаштування → ШІ-помічник). Укажи адресу сумісного Chat Completions API, назву моделі та свій API-ключ. Натисни **«Подключить и проверить»** (Підключити й перевірити).

Біля завдання відкрий **«Помощь ИИ»** (Допомога ШІ), за потреби встав свій код і запитай підказку.

| Що надсилається | Що зберігається |
| --- | --- |
| Коротка перевірка підключення; за запитом підказки — контекст завдання, приклад, поточна відповідь, вставлений код і запитання | Адреса й назва моделі зберігаються. Ключ залишається в пам’яті до відключення моделі або закриття застосунку. |

Запити йдуть безпосередньо обраному провайдеру. Діють його тарифи й обмеження. Для віддаленого API потрібен HTTPS. Окремо встановлена локальна модель може працювати без інтернету за адресою на зразок `http://localhost:11434/v1`. Помічник не читає файли, не запускає код і не змінює прогрес. Перевіряй його поради запуском програми.

## Технології та розробка

| Частина проєкту | Інструменти |
| --- | --- |
| Настільний застосунок | Python, PySide6 6.8.2.1, Qt Quick / QML |
| Локальні налаштування й прогрес | Qt `QSettings` |
| Web-практика | Flask 3.1+, SQLite, HTML / CSS, JSON |
| Перевірки | Python `unittest`, Qt Test, скрипти перевірки відображення |

```text
main.py / backend.py       Запуск і стан застосунку
curriculum.py             Структура курсів і формування уроків
core_content.py           Матеріали Python Core
web_content.py            Базові уроки й формування Web-курсу
web_extended_content.py   Зв’язки даних, користувачі й запуск
qml/                      Інтерфейс, значки й прев’ю тем
examples/                 Робочі навчальні проєкти
tests/ / tools/           Тести й інструменти розробки
docs/ / packaging/        Посібники й підготовка збірок
```

Після встановлення залежностей застосунку та Web-прикладів запусти тести:

```bash
python -m unittest discover -s tests -v
```

На Linux без видимого вікна додай перед командою `QT_QPA_PLATFORM=offscreen QT_QUICK_BACKEND=software`.

Перед внеском у проєкт прочитай [AGENTS.md](AGENTS.md). Роби зміни в межах однієї задачі й додавай потрібні перевірки. Про відтворювану помилку повідом у [GitHub Issues](https://github.com/unbowed-scripts/PythonTech/issues), не публікуючи ключі й особисті дані.

<details>
<summary><strong>Якщо щось не працює</strong></summary>

- **Застосунок не запускається:** установлюй залежності й запускай програму в одному середовищі. У ньому має бути PySide6 з Qt Quick.
- **`No module named flask`:** установи `examples/web_notes/requirements.txt` тим Python, яким запускаєш приклад.
- **Порт 5000 зайнятий:** додай `--port 5001` до команди Flask і відкрий [localhost:5001](http://127.0.0.1:5001/).
- **ШІ не підключається:** перевір адресу, ідентифікатор моделі, ключ і обмеження провайдера. Навчатися можна офлайн.
- **Відповідь не зараховується:** перевір регістр і пробіли всередині відповіді. Пробіли на початку й у кінці не враховуються.

</details>
