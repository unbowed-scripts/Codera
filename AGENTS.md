# Работа с учебным текстом

Перед работой над уроком продумай понятную подачу теории. Не оформляй её одной длинной строкой или сплошным абзацем.

- Разделяй объяснение на короткие смысловые абзацы: основная мысль, правила, ограничения и пример.
- Выделяй ключевую мысль жирным; не выделяй весь текст. Для теории поддерживается HTML (`<p>`, `<b>`, `<ul>`, `<li>`, `<code>`); символы `<`, `>` и `&` в примерах экранируй.
- Формулируй текст простыми словами. Шаги самостоятельной работы и критерии проверки оформляй отдельными пунктами.
- Сохраняй точность объяснений, рабочие примеры кода и совместимость ответов.
- После изменения текста сделай небольшую проверку отображения в приложении: обычная и узкая ширина окна, переносы, выделения, отсутствие обрезания и видимой разметки.
- Если задача касается только текста, сохраняй текущий дизайн: цвета, шрифты, размеры, отступы и расположение элементов.

# UI/UX Design Documentation

Перед изменением интерфейса изучи официальные рекомендации и применяй их с учётом Qt Quick/QML:

- Material Design 3: https://m3.material.io/
- Radix Themes — цвета: https://www.radix-ui.com/themes/docs/theme/color
- Radix Themes — типографика: https://www.radix-ui.com/themes/docs/theme/typography
- Apple Human Interface Guidelines: https://developer.apple.com/design/human-interface-guidelines
- Tailwind CSS — адаптивность: https://tailwindcss.com/docs/responsive-design
- Motion for React: https://motion.dev/docs/react — только если проект использует React.

Для настроек тем используй карточки с реальными скриншотами меню, явной отметкой выбора и управлением с клавиатуры. Скриншоты обновляются командой `.venv/bin/python tools/capture_theme_previews.py`. После изменений проведи одну общую проверку поведения и отображения на обычной и узкой ширине.
