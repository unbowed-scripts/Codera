# Python Core → Web

54 урока, 108 коротких проверок и 54 задания с самостоятельным написанием кода.
Курс рассчитан на Python 3.10+; все примеры используют стандартную библиотеку.

## Как учиться

1. Прочитай объяснение и предскажи результат примера.
2. Запусти пример в отдельной учебной папке. Измени одно значение и объясни разницу.
3. Реши две короткие проверки в приложении.
4. Выполни «Напиши сам» в своём `.py`-файле, проверь каждый критерий.
5. Отметь практику только после запуска. На следующий день воспроизведи главное без подсказки.

Не нужно выдерживать фиксированное число уроков в день. Если не получается объяснить пример своими словами, вернись к нему перед следующей темой. Через каждые шесть уроков повтори одну старую задачу с другими данными.

В приложении раздельно сохраняются результаты коротких проверок и твои отметки практики. Приложение не запускает и не оценивает самостоятельно написанный код. Старые отметки первых уроков сохраняются; отметки практики из них автоматически не создаются.

## Итоговый проект: трекер привычек

Начни со своей реализации. Ориентир в `examples/habit_tracker/` открывай после первой попытки.

Модель привычки: стабильный строковый `id`, непустое `name`, список уникальных дат `days` в формате `YYYY-MM-DD`.
Команды: добавить, показать список, отметить день, удалить по ID.

Раздели проект:

- `service.py`: правила и проверки, без ввода и файлов.
- `storage.py`: чтение, проверка структуры и сохранение JSON.
- `__main__.py`: аргументы командной строки, сообщения и код завершения.
- `tests/`: повторяемые проверки с временными файлами.

Минимальные сценарии приёмки:

| Сценарий | Ожидаемый результат |
| --- | --- |
| Первое чтение без файла | Пустой список |
| Добавление «  Python  » | Название «Python» и новый ID |
| Пустое название | Ошибка, данные не меняются |
| Перезапуск | Привычки и отметки восстановлены |
| Одна и та же дата дважды | Одна отметка |
| 2024-02-29 / 2023-02-29 | Первая дата допустима, вторая отклоняется |
| Неизвестный ID | Понятная ошибка без изменения файла |
| Повреждённый JSON или неверные поля | Ошибка; исходный файл не перезаписывается |
| Ошибка сохранения | Не сообщать об успехе; прежний файл сохраняется |
| Удаление привычки | Остальные привычки и их ID не меняются |

Учебный ориентир рассчитан на один локальный процесс. Атомарная замена файла защищает от частично записанного JSON, но не решает конкурентное редактирование двумя процессами. Для веб-приложения изучи базу данных, транзакции и конкурентные запросы.

Запуск ориентира из корня PythonTech:

```sh
python -m examples.habit_tracker --help
python -m examples.habit_tracker --file habits.json add "Учить Python"
python -m examples.habit_tracker --file habits.json list
# Скопируй настоящий ID из списка вместо ID:
python -m examples.habit_tracker --file habits.json mark ID --date 2024-03-01
python -m examples.habit_tracker --file habits.json delete ID
python -m unittest discover -s tests -p test_habit_tracker.py -v
```

В Windows команду `python` при необходимости замени на `py`.

## Проверка готовности к Web

Выполни без копирования готового решения:

1. За 5 минут объясни разницу: `==` / `is`, `print` / `return`, список / генератор, класс / объект, аннотация / проверка.
2. Напиши функцию поиска привычек по части имени. Покрой пустой запрос, отсутствие совпадений и кириллицу тестами.
3. Прими словарь `{"id": "...", "day": "2024-03-01"}` в отдельной функции. Проверь поля, вызови правило отметки, верни словарь с результатом. Внутри не должно быть `input()` или `print()`.
4. Воспроизведи ошибку сохранения и докажи, что прежние данные остались доступны.
5. Создай новое окружение, запусти проект и тесты по своему README.
6. Объясни весь путь данных: текст → проверка → модель → действие → сохранение → результат.

Считай базу освоенной, когда можешь выполнить эти пункты, исправить причину падения теста и добавить небольшую возможность без переписывания всего проекта. Если затрудняешься: пункты 1–2 → функции и коллекции; 3 → контракты; 4 → файлы и тесты; 5 → инструменты.

## Что дальше

Последовательность Web: клиент/сервер → HTTP и URL → HTML/CSS и формы → обработчики и JSON → SQL и SQLite → веб-фреймворк → тестирование запросов → безопасность и развёртывание.

Перед асинхронным фреймворком отдельно изучи `async def`, `await`, задачи и блокирующие операции. `async` помогает перекрывать ожидание, но не делает произвольное вычисление автоматически быстрее. Потоки, процессы, метаклассы и написание дескрипторов — дальнейшее углубление, а не обязательная преграда перед первым веб-приложением.

В версии 0.5.0 Python Web содержит 24 доступных урока, четыре итоговых теста и четыре мини-проекта. Курс ведёт от HTTP к локальному сервису заметок на Flask и SQLite. Уроки можно читать офлайн; Flask нужен отдельно для выполнения примеров. [Запуск итогового сервиса](../examples/web_notes/README.md).

## Первоисточники

Авторские объяснения и примеры курса можно сверять с официальными справочниками:

## Завершение каждого раздела

После успешного разбора заданий во всех шести уроках раздела Python Core открывается отдельная страница «Тест и мини-проект». Она доступна со страницы раздела, через кнопку после шестого уровня и через продолжение обучения в обзоре.

1. Ответь на шесть коротких вопросов — по одному из каждого уровня.
2. Разбери два фрагмента кода и выбери объяснение их частей. Для прохождения нужны все восемь верных ответов; попытки не ограничены.
3. После теста напиши собственный мини-проект. Подсказки открываются последовательно. Готовый пример можно раскрыть, скопировать и изучить вместе с разбором.
4. Проверь свою версию по критериям, затем отметь её выполнение. Это самостоятельная проверка, а не автоматическая оценка исходного кода.

Тесты и проекты сохраняются отдельно от 54 уроков и их практики. Уроки по-прежнему доступны для свободного просмотра. В самой практике уроков есть раскрывающаяся подсказка с опорным правилом и отсылкой к разобранному примеру.

Материалы девяти итогов находятся в `section_content.py`. Небольшая проверка взаимодействий: `.venv/bin/python -m unittest discover -s tests -p test_checkpoint.py -q`.
