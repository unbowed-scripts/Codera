# Хранение данных

В локальной версии 0.8.0 добавлены файлы проектов, окружения Python и чек-листы. API-ключи сохраняются в системном защищённом хранилище; в QSettings остаются только параметры подключения. Подробности: [Рабочее пространство](WORKSPACE.md).

## Учебные данные, начиная с 0.7.0

**Готовые сборки читают уроки из сжатого архива `courses.zip`.** Интернет и распаковка на диск не нужны. Исходные тексты для редактирования остаются в Python-модулях репозитория.

## Учебные материалы

- `curriculum_source.py` собирает уроки из исходников; `section_source.py` собирает мини-проекты.
- `tools/pack_courses.py` сохраняет идентификаторы, структуру курсов, уроки и проекты в ZIP с JSON. Формат архива имеет собственную версию.
- `curriculum.py` выбирает архив, если он находится рядом с модулем. Без архива используется исходный каталог.
- `content_archive.py` читает отдельный урок при обращении. Кэш удерживает не более 12 уроков; после превышения удаляется самый давно использованный. Повторное открытие заново читает урок из архива.
- Список разделов, идентификаторы и мини-проекты загружаются целиком. Ограничение кэша относится только к урокам, а не ко всей памяти приложения.
- Проверка наличия урока и просмотр его идентификатора не загружают текст. Навигация использует индексы, построенные при запуске.

Архив генерируется при сборке Windows, Linux и при подготовке Android. Модули с исходными уроками и проектами не включаются в готовую настольную сборку. Не редактируй архив вручную: измени исходники и собери его заново.

```bash
.venv/bin/python tools/pack_courses.py
```

Для материалов 0.7.0: 360 817 байт JSON превращаются в архив размером 149 609 байт, включая индекс и служебные данные ZIP. Экономия — 58,5% относительно этого JSON. Это не сравнение размеров установщиков: Python и Qt занимают основную часть готового приложения.

## Прогресс

Прогресс и настройки по-прежнему хранятся через Qt `QSettings`. Имена ключей и идентификаторы уроков не изменены. Сохраняются списки пройденных уроков, выполненной практики, тестов и проектов, а не копии учебных текстов или история каждой попытки. Повторная отметка не добавляет дубликат.

Переход на 0.7.0 не требует переноса прогресса. Автотест проверяет чтение прежнего формата и сохранение полного прогресса в INI размером менее 8 КиБ. Размер системного хранилища на Windows может отличаться. Черновики ответов и вопросы ИИ остаются в памяти на время сеанса; эта версия не добавляет их сохранение после закрытия.

## Проверка изменений

```bash
QT_QPA_PLATFORM=offscreen QT_QUICK_BACKEND=software .venv/bin/python -m unittest discover -s tests -v
```

Тесты сравнивают каждый урок, ответ и проект с исходником, проверяют ограничение кэша, воспроизводимость архива и полный учебный маршрут в отдельном процессе без исходных модулей контента. CI проверяет запуск упакованного приложения на Linux и установленного приложения на Windows перед публикацией.

Каталоги разработчика `build`, `dist` и `.venv` не являются пользовательским прогрессом. Удаление пользовательских настроек не уменьшает эти каталоги.
