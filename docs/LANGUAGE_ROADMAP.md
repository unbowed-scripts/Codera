# Каталог и развитие языковых курсов

Сейчас опубликован Python Core. Остальные языки представлены аватарками, описанием назначения, планом из шести разделов и итоговым проектом. Это программы будущих курсов, не готовые уроки. Сроки публикации не назначены.

Первый этап: Python, JavaScript, TypeScript, Java, C#, C++, C, Go, PHP и SQL. SQL выделен как язык запросов для работы с данными. Порядок карточек — учебный приоритет, а не точный мировой рейтинг.

Выбор основан на распространённости языков и покрытии разных задач:

- [GitHub Octoverse 2025](https://github.blog/news-insights/octoverse/octoverse-a-new-developer-joins-github-every-second-as-ai-leads-typescript-to-1/) выделяет Python, JavaScript, TypeScript, Java, C++ и C# среди основных языков новых репозиториев.
- [Stack Overflow Developer Survey 2025](https://survey.stackoverflow.co/2025/) дополняет картину использования технологий разработчиками. Это ориентиры выбора, а не обещание неизменного рейтинга.

Следующий этап: Rust, Kotlin, Swift, Dart и Ruby. Это расширение по специализациям; оно не означает, что каждый из этих языков менее популярен любого языка первого этапа во всех рейтингах.

Для каждого будущего курса планируется тот же учебный цикл: шесть уровней в разделе, понятная теория, пример с разбором, практика с подсказками, итоговый тест и мини-проект. TypeScript предполагает знакомство с JavaScript. Планы можно уточнять до публикации.

Каталог хранится в `language_catalog.py`, аватарки — в `qml/icons/languages`, интерфейс — `Landing.qml` и `LanguagePlan.qml`. Изображения включаются в установщик вместе с QML и не требуют интернета. Перед переводом курса в доступные необходимо реализовать его собственные уроки и переход: сейчас запуск обучения ведёт в Python Core.
