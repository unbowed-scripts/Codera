# PythonTech 0.8.0

- Рабочее пространство в практике и мини-проектах: файлы проекта, редактор и встроенный терминал.
- Критерии задания слева с сохраняемыми отметками. «Готово» отмечает практику и открывает следующий урок или итог раздела. Проверка ответов остаётся отдельной.
- Терминал в отдельном окне: ввод команд, цвета ANSI, задачи и переход к следующему уроку.
- Настройки шрифта, импорт TTF/OTF, размер текста, готовые темы и собственные цвета.
- Настраиваемая оболочка терминала. Перед первым запуском предлагается установить Python и подготовить пакеты курса.
- Загрузка Python 3.13 через uv, отдельное окружение `.venv`, pip и зависимости Web.
- Сохранение API-ключа в защищённом системном хранилище после проверки подключения. При недоступном хранилище ключ остаётся только в памяти.
- Сохранена совместимость идентификаторов уроков и прежнего прогресса.

Инструкция и ограничения: [Рабочее пространство](https://github.com/unbowed-scripts/PythonTech/blob/v0.8.0/docs/WORKSPACE.md).

Сборки Windows и Linux проходят автоматические проверки в GitHub Actions. Сохранение ключей проверено с подменой хранилища; настоящее системное хранилище и macOS требуют отдельной проверки. Новые возможности относятся к настольному приложению; Android остаётся отдельным экспериментальным направлением.
