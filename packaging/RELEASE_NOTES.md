# PythonTech 0.7.0

Учебные материалы в готовых сборках хранятся компактнее и загружаются по мере открытия. Обучение по-прежнему работает офлайн, сохранённый прогресс совместим с 0.6.0.

## Что изменилось

- Уроки и мини-проекты упакованы в сжатый архив без распаковки на диск. Для текущего курса архив занимает 149 609 байт вместо 360 817 байт несжатого JSON: экономия 58,5%. Это размер учебных данных, а не всего приложения.
- Тексты уроков читаются при открытии. Кэш хранит до 12 последних использованных уроков. Метаданные курсов и мини-проекты загружаются целиком.
- Навигация использует заранее подготовленные индексы уроков и разделов.
- Прогресс сохраняет прежние ключи и формат. Полное прохождение проверяется с хранилищем INI размером менее 8 КиБ; без копирования уроков и истории попыток.
- Автоматические проверки сравнивают все упакованные материалы с исходниками и проверяют работу без исходных модулей курсов. Перед сборкой установщиков запускается весь набор тестов.

Содержание курса сохранено: 96 уроков Core и Web, 192 вопроса в уроках и 16 итоговых тестов и мини-проектов. Приложение не запускает код ученика. Практику и проекты пользователь отмечает после самостоятельной проверки. Черновики ответов пока не сохраняются после закрытия.

## Установка

- Windows x64: `PythonTech-0.7.0-windows-x64-setup.exe`.
- Ubuntu / Debian x64: `PythonTech-0.7.0-linux-amd64.deb`.
- Linux x64: `PythonTech-0.7.0-linux-x64.tar.gz`.
- Контрольные суммы: `SHA256SUMS.txt`.

Python для готового приложения устанавливать не нужно. Размер сборки в основном определяется Python и Qt. Android остаётся отдельным предварительным выпуском 0.7.0-alpha.1; этот выпуск содержит настольные сборки.

Перед публикацией CI проверяет запуск Linux-сборки и установку с запуском на Windows. Это не полная проверка каждой функции на всех системах. Подпись Git-коммита и тега не является цифровой подписью Windows-установщика.
