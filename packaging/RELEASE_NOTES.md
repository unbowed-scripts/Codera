# PythonTech 0.4.0

## Добавлено

- Меню языка интерфейса: русский выбран; English и Українська пока недоступны и отмечены «Скоро».
- Выбор четырёх тем: зелёной, синей, серой и светлой. Реальные скриншоты со скошенными краями расположены в один ряд; выбор сохраняется.
- Журнал обновлений и кнопка «О разработке» с информацией об Unbowed / byteix и идее бесплатного обучения с открытым исходным кодом.
- Итоговые тесты и мини-проекты разделов Python Core, подсказки и критерии самопроверки.
- Каталог языков с аватарками и программами будущих курсов.

## Изменено

- Учебная теория разбита на короткие смысловые абзацы с выделением основных правил.
- Настройки доступны с клавиатуры. На узком экране темы прокручиваются горизонтально.
- Документация дополнена схемами настроек, навигации и подготовки сборок.

## Запуск

- Windows x64, портативная сборка: распакуйте весь `PythonTech-0.4.0-windows-x64-portable.zip` и запустите `PythonTech/PythonTech.exe`. Сохраняйте папку `app` рядом с программой.
- Windows x64, установщик из Windows CI: `PythonTech-0.4.0-windows-x64-setup.exe`.
- Linux x64: установите `.deb` через `sudo apt install ./PythonTech-0.4.0-linux-amd64.deb` или распакуйте `.tar.gz` и запустите `PythonTech/PythonTech`.

Python и pip для запуска сборок не нужны. Для собственных учебных программ установите Python отдельно. Требования Linux зависят от системы сборки: актуальная минимальная libc указана в зависимостях `.deb`; CI использует Ubuntu 22.04. Локальная портативная сборка Windows требует отдельной проверки на Windows; её упаковка на Linux не подтверждает запуск.

Прогресс и настройки сохраняются в пользовательском профиле. Учебные материалы остаются на русском. Android APK в этот релиз не включён: работа над ним отложена до отдельного подтверждения автора.
