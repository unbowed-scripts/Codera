# PythonTech 0.6.0

Учебное приложение для самостоятельного изучения Python. Этот выпуск объединяет расширенный курс Web, обновлённые объяснения и документацию на трёх языках.

## Что нового

- Python Web: 42 урока и семь мини-проектов — от HTTP и Flask до связанных таблиц, регистрации, прав доступа и подготовки запуска.
- Три полных учебных приложения с тестами: заметки, каталог книг и личный планировщик задач.
- Всего в Core и Web: 96 уроков, 192 вопроса в уроках и 16 итоговых тестов и мини-проектов.
- Более понятные уроки, задания, подсказки и тексты интерфейса.
- README на английском, русском и украинском. Язык самого интерфейса пока русский.
- Необязательный ИИ-помощник через совместимый API с контекстом выбранного задания.

Обучение и обычные подсказки работают офлайн. Можно сразу открыть любой урок. Итоговые проверки разделов доступны после прохождения их уроков. Сохранённый прогресс совместим с новой версией.

## Загрузка и запуск

- **Windows x64:** скачайте `PythonTech-0.6.0-windows-x64-setup.exe` и запустите установщик.
- **Ubuntu / Debian x64:** скачайте `PythonTech-0.6.0-linux-amd64.deb` и установите через `sudo apt install ./PythonTech-0.6.0-linux-amd64.deb`.
- **Linux x64, архив:** распакуйте `PythonTech-0.6.0-linux-x64.tar.gz` и запустите `PythonTech/PythonTech`. Могут понадобиться системные библиотеки Qt, перечисленные в README.
- `SHA256SUMS.txt` содержит контрольные суммы файлов.

Python для готового приложения устанавливать не нужно. Для самостоятельного запуска учебных Web-проектов нужны Python и Flask; команды приведены в README.

Сборки подготовлены на Windows Server 2022 и Ubuntu 22.04. Перед публикацией проверяется запуск Linux-приложения и установка с запуском приложения на Windows. Это короткая проверка запуска, а не полная проверка всех функций на всех системах.

## Что произошло с 0.5.0

Версия 0.5.0 опубликована отдельно с исходниками и пояснением: автоматические проверки на Windows остановили подготовку установщика. Версия 0.6.0 включает её изменения и расширенный учебный материал.
