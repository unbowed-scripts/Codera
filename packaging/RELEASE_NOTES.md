PythonTech 0.3.0 — темы оформления и установщики

- Четыре темы: зелёная, синяя, серая и светлая. Выбор сохраняется.
- Выпадающий список направлений оформлен под выбранную тему.
- Убраны всплывающие подсказки у тем, ускорены прокрутка и переходы.
- 54 урока Python Core, 108 проверок и 54 самостоятельные практики.

Windows x64: скачайте файл `windows-x64-setup.exe` и запустите установщик.
Linux Ubuntu 22.04+ / Debian 12+ x64: установите `.deb` через `sudo apt install ./PythonTech-0.3.0-linux-amd64.deb`.
Другие совместимые Linux: распакуйте `.tar.gz` и запустите `PythonTech/PythonTech`.
Python и pip для запуска установленных сборок не нужны. Для самостоятельного написания учебных программ установите Python отдельно.

Установщики не подписаны сертификатом издателя. Прогресс и настройки сохраняются в пользовательском профиле и не удаляются при обновлении приложения.
