# PythonTech 0.5.0

- Заполнен Python Web: 24 урока в четырёх разделах — HTTP, Flask, данные и безопасность, тестирование и итоговый сервис.
- Добавлены 48 вопросов в уроках, четыре итоговых теста и четыре мини-проекта с примерами, пошаговыми подсказками и критериями.
- Добавлен работающий локальный сервис заметок: HTML, JSON API, SQLite, поиск, редактирование, удаление и тесты.
- В подсказках практики появились блоки кода.
- Можно подключить собственную модель через совместимый API. Помощник учитывает выбранное задание, ответ и вставленный код; API-ключ хранится только в текущем запуске.
- README переписан для пользователей: установка, обучение, Web-практика, настройки и решение частых проблем.
- Прогресс Python Core и Web учитывается отдельно. Существующие отметки Core сохраняются.

Приложение и обычные подсказки работают офлайн. Для запуска Web-примеров Flask
устанавливается отдельно один раз. ИИ необязателен; удалённые запросы отправляются
на адрес, указанный самим пользователем.

Версия исходников — 0.5.0. Готовые сборки доступны после публикации на странице релизов.
