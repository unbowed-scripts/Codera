# PythonTech 0.7.0-alpha.1 — Android ARM64

Первый тестовый APK на основе настольной версии 0.6.0: 96 уроков Python Core и Web, практика и мини-проекты.

## Установка

Скачайте **PythonTech-0.7.0-alpha.1-android-arm64.apk** на телефон с Android 9 или новее и процессором ARM64. Откройте файл и разрешите установку для приложения, через которое его открываете.

Уроки доступны офлайн и в любом порядке. ИИ-помощник необязателен и использует сеть при подключении к внешнему API. Приложение не запускает код ученика.

## Статус проверки

- APK собран для `arm64-v8a`, versionCode — `70001`.
- Проверены цифровая подпись APK, сведения о пакете и наличие исходников учебных проектов.
- **Запуск на реальном Android-устройстве не проверен.** Это alpha-версия для первых испытаний, возможны ошибки запуска, отображения и управления.
- Устройства с размером страницы памяти 16 КБ отдельно не проверены.
- APK подписан тестовым Android-ключом; подпись Git-коммита и тега — отдельная подпись автора.

После установки проверьте открытие урока, прокрутку, поворот экрана и сохранение прогресса после перезапуска. При сообщении об ошибке укажите модель телефона, версию Android и шаги воспроизведения.

`SHA256SUMS-android.txt` содержит контрольную сумму APK. Инструкция сборки находится в `docs/ANDROID.md`. Стабильные сборки Windows и Linux остаются в релизе **0.6.0**.
