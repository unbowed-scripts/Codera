# Локальный сервис заметок

Итоговый пример Python Web: HTML-формы, JSON API, SQLite, поиск, создание,
редактирование и удаление. Все ресурсы локальные. Входа и разделения пользователей
нет: пример предназначен для своего компьютера.

Из корня PythonTech, в активированном окружении Python 3.10+:

```bash
python -m pip install -r examples/web_notes/requirements.txt
python -m flask --app examples.web_notes.app run
```

Открой `http://127.0.0.1:5000/`. Или скопируй `app.py` в отдельную папку,
установи Flask и запусти `python app.py`. Ctrl+C останавливает сервер.

Данные сохраняются в `notes.sqlite3` рядом с `app.py`. Перезапуск их не удаляет.
`NOTES_DB` меняет путь базы. `NOTES_SECRET` задаёт постоянный ключ сессии:
сгенерируй его через `python -c "import secrets; print(secrets.token_hex(32))"`
и сохрани в окружении, не в коде. Без него случайный ключ меняется после
перезапуска: открой страницу заново, чтобы получить новый токен формы.

HTML-формы отправляют скрытый CSRF-токен. Для API используй клиент с сохранением cookie:
сначала `GET /api/csrf`, затем значение `csrf` передавай в `X-CSRF-Token`.

| Запрос | Результат |
| --- | --- |
| `GET /api/notes?q=Web` | Список и поиск, 200 |
| `GET /api/notes/1` | Одна заметка, 200 или 404 |
| `POST /api/notes` с JSON `{"title":"Учить Web"}` | Создание, 201 и Location |
| `PATCH /api/notes/1` с JSON `{"title":"Повторить Web"}` | Изменение, 200 |
| `DELETE /api/notes/1` | Удаление, 204 без тела |

Заголовок — строка от 1 до 80 символов после удаления внешних пробелов.
SQL использует параметры, шаблон экранирует HTML. GET не изменяет заметки.

Проверки выполняются без сети во временной базе:

```bash
python -m unittest discover -s examples/web_notes -p "test_*.py" -v
```

Собственная практика: добавь категории, фильтр по категории и тесты. Для публикации
понадобятся вход, права доступа, HTTPS, WSGI-сервер и резервные копии: локальный
учебный пример этого не предоставляет.
